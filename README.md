# Mrudula Mestri — Portfolio Website

A responsive personal portfolio built with plain HTML, CSS, and JavaScript. No build step or framework required.

## Preview locally
1. Extract the folder if downloaded as a ZIP.
2. Open `index.html` in a browser, or use VS Code's Live Server extension.

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `mrudula-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After deployment, GitHub will display the public website URL in the Pages section.

## Before publishing
- Replace generic GitHub profile links on project cards with each project's direct repository URL once available.
- Add a resume PDF link if you want recruiters to download your resume.
- Confirm all project descriptions accurately reflect your own contribution, particularly eQMS 360.
- Add a professional photo only if you want one; the current design does not require it.
- Verify your email and links on mobile and desktop.
